### Pengolahan dan Transfer Data Media Menggunakan Base64 dalam Python dan Eel

<!-- halaman 3 -->
## Arsitektur Eel
Aplikasi desktop berbasis Eel memisahkan logika kerja menjadi dua sisi yaitu Python sebagai backend dan browser web sebagai antarmuka frontend. Keduanya saling terhubung melalui protokol WebSocket yang sangat andal untuk bertukar data teks maupun JSON. Namun, aplikasi modern tentu tidak hanya mengolah teks, kebutuhan menampilkan dan mengelola media lokal seperti foto profil atau dokumen visual juga menjadi fitur penting yang harus ditangani

<!-- halaman 4 -->
### Masalah Transfer Berkas Media
Jalur komunikasi WebSocket pada Eel dirancang optimal untuk pesan berbasis teks, bukan aliran data biner mentah (raw bytes). Mengirimkan berkas gambar langsung melalui jalur ini berisiko memicu kerusakan karakter atau format (corrupt) dan fragmentasi data. Di sinilah **Base64** berperan dimana menyandikan data biner gambar menjadi untaian teks ASCII murni sehingga aman dikirim bolak-balik antara Python dan browser tanpa perlu menyiapkan web server eksternal

<!-- halaman 5 -->
Konsep Base64 dan Skema Data URI** Base64 bekerja dengan memecah setiap 3 byte biner menjadi 4 karakter teks ASCII. Proses ini menambah ukuran data sekitar 33%, sehingga sangat ideal untuk media ringan seperti foto profil atau ikon antarmuka. Agar string teks ini bisa langsung ditampilkan oleh tag <img> tanpa membuat berkas sementara, peramban menggunakan skema Data URI dengan format baku: **data:image/png;base64,[payload_data]

<!-- halaman 6 -->
**Alur Transfer Data Dua Arah** Mekanisme pertukaran media terbagi menjadi dua skenario utama:

1. **Python ke JavaScript (Menampilkan Citra):** Python membaca file biner dari penyimpanan lokal, mengubahnya menjadi string Base64 dengan header MIME, lalu mengirimkannya ke antarmuka untuk disematkan langsung pada atribut src tag <img>

2. **JavaScript ke Python (Unggah Berkas):** Pengguna memilih gambar melalui browser, dibaca secara asinkron menjadi Data URI via FileReader, lalu dikirim ke Python untuk dipisahkan headernya dan disimpan kembali sebagai berkas biner

<!-- halaman 7 -->
Implementasi Sisi Backend (Python)** Modul bawaan **base64** menangani proses konversi di sisi server tanpa memerlukan pustaka eksternal. Untuk membaca citra, berkas dibuka dalam mode biner **(rb)**, disandikan via **base64.b64encode()**, lalu digabungkan dengan header MIME sebelum dikirim ke antarmuka. Sebaliknya, saat menerima data dari peramban, header skema Data URI wajib dipisahkan terlebih dahulu menggunakan **split(‘, ’, 1)** agar payload teks murni dapat didekode dengan **base64.b64decode()** dan ditulis kembali ke penyimpanan lokal dalam mode biner **(wb)

<!-- halaman 8 -->
HOME **ABOUT** MORE **Implementasi Sisi Frontend (JavaScript)** Pada sisi antarmuka, objek bawaan **FileReader** digunakan untuk membaca berkas melalui yang dipilih pengguna tag **<input type="file">** secara asinkron. Method **readAsDataURL()** secara otomatis mengubah berkas biner tersebut menjadi untaian string Data URI lengkap. Nilai ini dapat langsung dipasang ke atribut **src** elemen gambar untuk pratinjau instan di layar, sekaligus dikirimkan ke fungsi Python melalui jembatan fungsi Eel tanpa memerlukan proses form submission konvensional
