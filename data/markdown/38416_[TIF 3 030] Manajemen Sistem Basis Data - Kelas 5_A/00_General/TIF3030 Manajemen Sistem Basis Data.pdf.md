# 2. Informasi Umum Mata Kuliah
Mata kuliah Manajemen Sistem Basis Data membahas prinsip dan praktik pengelolaan basis data pada tingkat lanjut. Mata kuliah ini mengasumsikan mahasiswa telah menguasai keterampilan dasar RDBMS (instalasi, CRUD, join, view, trigger) dari mata kuliah Sistem Basis Data, sehingga pembahasan langsung difokuskan pada aspek manajerial dan lanjutan. Paruh pertama perkuliahan (Minggu 1–8) membahas manajemen basis data relasional tingkat lanjut, meliputi peran dan tanggung jawab Database Administrator (DBA), tata kelola data (data governance), analisis kebutuhan kapasitas dan kinerja, strategi backup dan recovery, keamanan dan kontrol akses, optimasi kinerja (indexing, query tuning), serta transaksi dan kontrol **Deskripsi Mata Kuliah** konkurensi. Paruh kedua (Minggu 9–16) membahas basis data non-relasional (NoSQL) secara mendalam, mencakup konsep dan taksonomi NoSQL, model key-value, document-oriented, column-family, dan graph, skalabilitas (sharding, replikasi, model konsistensi), basis data NoSQL berbasis cloud, integrasi big data untuk kecerdasan buatan, hingga perancangan arsitektur polyglot persistence yang menggabungkan basis data relasional dan non-relasional. Mahasiswa dilatih merancang dan mengelola proyek implementasi basis data hybrid sehingga siap berperan sebagai pengelola basis data pada organisasi berskala kecil hingga menengah.
